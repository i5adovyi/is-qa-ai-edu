# Lab 03 hints

<details><summary>Hint 1 — Known and allowed are separate</summary>

An external allowlist is necessary but insufficient. This exercise knows only one tool, `read_ticket`.

</details>

<details><summary>Hint 2 — Check shape before indexing</summary>

Validate the argument object and its exact key set before reading `arguments["ticket_id"]`.

</details>

<details><summary>Hint 3 — Short-circuit the conjunction</summary>

Use a sequence of guards or a Boolean expression ordered from structural checks to value checks. Require a string and exact scope match. The function must return an actual Boolean.

</details>
