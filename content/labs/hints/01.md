# Lab 01 hints

<details><summary>Hint 1 — Preserve the rest of the string</summary>

Use substitutions on matched spans instead of splitting on spaces. Splitting often changes punctuation or whitespace.

</details>

<details><summary>Hint 2 — Bound the credential pattern</summary>

The synthetic key's alphabet is explicitly defined. A wildcard such as `.*` can consume the remainder of a useful error message.

</details>

<details><summary>Hint 3 — Two independent substitutions</summary>

Use one pattern for email-like addresses and a second for `sk-demo-` followed by allowed key characters. The replacements `[EMAIL]` and `[KEY]` should not match either original pattern, which makes repeated application stable.

</details>
