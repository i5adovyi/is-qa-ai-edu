# Delegate a bounded piece of work

## Outcome

What artifact must the worker deliver, and how will the integrator use it?

## Ownership

List files or data the worker owns. List shared interfaces it may read but must not change. Name the integrator.

## Minimal context

Provide the objective, constraints, relevant source excerpts, and exact schema or API contract. Avoid forwarding unrelated conversation history.

## Acceptance and verification

Name checks the worker must run and evidence it must return. Include one expected rejection or failure path.

## Budget and escalation

Set a deadline or action budget. Specify when to stop and which unresolved decisions require the integrator.

## Return format

Completed artifacts; checks and results; assumptions; unresolved problems; integration instructions. A final status message should not claim work that is only planned.

## Integration review

Verify contracts, source provenance, independent test results, and conflicting changes. Compare the total cost with one worker performing the same task.
