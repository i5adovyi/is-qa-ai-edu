# Recall queue

Create one row for a mistake you actually made or an explanation you could not defend. Do not fill a queue with every term in the course.

| ID | Source exercise/attempt | Misconception | New-case prompt | Last attempt | Recall result | Next review | Next action |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | independent / hint needed / not yet | | |

Start with a revisit in your next available session. If you can explain and apply the idea without notes, choose a longer interval. If you need a hint or make the same error, shorten the next interval and reduce the task to one boundary. A few days followed by a week can be a starting experiment; no single spacing pattern is prescribed as optimal.

Keep dated responses and confidence before checking. Strong confidence plus a wrong answer deserves a different next action from uncertainty with a correct explanation. Retire a card only after a successful unfamiliar case after a delay, and retain its history.
