# Observe your own learning pace

Estimates are planning aids, not deadlines. Do not mark a task complete because its timebox expired.

| Date | Lesson/checkpoint | Route | Reading minutes | Guided minutes | Independent minutes | Optional minutes | Help requested | Next action |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | | |

After three sessions, compare observed minutes with the lesson estimates. Adjust your next session's scope. Note whether setup, accessibility needs, language, or unfamiliar programming added time. Do not infer ability from speed.

For a beginner trial, record the first artifact produced, the checkpoint where help was requested, and whether the learner could name the next action without seeing the target solution. The course's estimates remain provisional until actual learner observations support them.
