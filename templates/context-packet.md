# Prepare a decision context packet

## Decision to support

State the next decision in one sentence. Do not paste an entire conversation if only one question needs resolution.

## Authoritative instructions

List the applicable task constraints and their scope. State which system enforces permissions.

## Evidence inventory

| Source ID | Version or date | Relevant claim | Trust boundary | Included excerpt or location |
| --- | --- | --- | --- | --- |
| P-01 | Example only | Current support policy | Reference data, not action authority | Fill in |

## Conflicts and unknowns

Describe conflicting evidence and which source wins, if any. Mark missing facts instead of inventing them.

## Context allocation

Reserve space for instructions, evidence, tool results, and the answer. Record the unit used: characters, measured tokens, or an explicitly labeled approximation. Avoid claiming character count is a universal token count.

## Excluded material

Name what was omitted and how to retrieve it if needed. Preserve provenance when compressing.

## Handoff capsule

Goal, current state, completed checks, unresolved risk, next authorized action, and a pointer to the full evidence.
